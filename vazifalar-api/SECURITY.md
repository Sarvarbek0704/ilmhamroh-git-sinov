# Xavfsizlik siyosati

## Qo'llab-quvvatlanadigan versiyalar

| Versiya | Xavfsizlik tuzatishlari |
|---|---|
| 4.x (oxirgi minor) | ha |
| < 4.0 | yo'q |

## Zaiflik haqida xabar berish

**Ochiq issue, PR yoki izoh yozmang** — tuzatish chiqquncha hamma uni ko'radi.

1. GitHub'da repo → **Security** → **Report a vulnerability** (xususiy xabar; repo egasi yoqqan bo'lishi kerak). Yoqilmagan bo'lsa — egasiga
   profilidagi aloqa orqali, mavzu: `vazifalar-api zaiflik`.
2. Yozing: zaiflik turi, ta'sirlangan yo'l/fayl, takrorlash qadamlari, ta'sir (kim nimaga kira oladi). Haqiqiy foydalanuvchi ma'lumotini ilova qilmang.
3. Javob: 3 ish kuni ichida qabul qilindi xabari; tuzatish rejasi — 10 ish kuni ichida. Tuzatish chiqqach — CHANGELOG'da `security` deb, xohlasangiz ismingiz bilan.

Xavfsizlik modeli va tekshirilgan tahdidlar — [docs/XAVFSIZLIK.md](docs/XAVFSIZLIK.md), [docs/OWASP-API.md](docs/OWASP-API.md).
